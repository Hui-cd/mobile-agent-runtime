# ADR-001：Agent 使用稳定的三个设备工具

> 状态：Accepted
> 日期：2026-09-04

## 背景

模型需要观察设备、操作界面和调用 Android 系统能力。如果为截图、点击、输入、打开应用等分别注册工具，模型工具面会随平台能力增长，并把 Android 实现细节泄漏给 Agent。

## 决定

Agent 只使用三个稳定工具：

- `device_observe`：取得当前应用、页面语义、设备状态和可选截图；
- `device_act`：点击、输入、滚动、返回等前台界面动作；
- `device_invoke`：通过 Intent 等公开系统能力打开应用、URL、设置或其他白名单能力。

新增平台能力优先扩展结构化参数和 capability 描述，不增加同义工具。工具参数仍必须按具体动作严格校验。

## 结果

- Pi Agent 与 Android Runtime 通过小而稳定的契约解耦；
- 模型更容易选择正确工具；
- Android 与 iOS 可以共享工具面，同时如实返回能力差异；
- 单个 `params` 对象可能过宽，因此必须按 capability 做分支校验，不能把“工具少”变成“参数模糊”。

## 约束

模型不能访问任意 Shell、Android 对象或设备权限。工具执行后的结果必须回到 Agent 循环，不能把“调用已发出”当作“任务已完成”。
